## 1. Цель

Студент прошёл регистрацию, и расписания у него нет. Приложение в интерактивном режиме —
всплывающими подсказками — ведёт его до первой пары, с какого бы места он ни начинал: нет
факультета — к созданию факультета, нет группы — к созданию группы, нет пар — к первой паре.
Без администратора и без знания того, как устроены «цикл», «шаблон пары» и «генерация занятий».

**Кто такой «новичок».** Студент, в расписании которого нет ни одной пары: группы нет либо
`GET /pairs/group/{groupId}` пуст. Когда студент зарегистрировался, неважно — режим включается и
у тех, кто пришёл до этого спринта. Причина может быть любой:

| Чего нет | Откуда начинаются подсказки |
|---|---|
| университета | шаг «Университет» мастера |
| факультета | шаг «Факультет»: выбрать или создать свой |
| курса | шаг «Курс» |
| группы | шаг «Группа»: выбрать или создать свою |
| пар у группы | вкладка «Расписание» → «Расписание группы» |

**Что считается результатом.** На вкладке «Расписание» видны занятия на семестр по паре, которую
студент только что завёл сам. После этого интерактивный режим выключается.

## 2. Что есть сейчас

**Приложение — путь, по которому поведут подсказки**

Экраны для всего пути уже есть; подсказки их связывают и объясняют.

| # | Экран | Что делает студент |
|---|---|---|
| 1 | Шаг «Университет» (`StudentSetupUniversityScreen`) | выбирает; если нет в списке — оставляет заявку |
| 2 | Шаг «Факультет» (`StudentSetupFacultyScreen`) | выбирает или «Создать факультет» → форма из одного поля |
| 3 | Шаг «Курс» (`StudentSetupYearScreen`) | выбирает 1–6 |
| 4 | Шаг «Группа» (`StudentSetupGroupScreen`) | выбирает или «Создать группу» → форма |
| 5 | Финал мастера (`StudentSetupDoneScreen`) | читает «Готово — расписание уже доступно» |
| 6 | Вкладка «Расписание», пустое состояние | нажимает «Заполнить расписание группы» |
| 7 | «Расписание группы» (`GroupScheduleScreen`) | нажимает «+ Добавить» |
| 8 | «Добавить занятие» (`PairFormScreen`) | день недели, чётность, номер пары, курс, аудитория → «Сохранить» |
| 9 | «Расписание группы» | нажимает «Сгенерировать занятия на семестр» и подтверждает — **шаг убирается** |
| 10 | Вкладка «Расписание» | видит занятия |

Что не так сейчас:
- Мастер заканчивается на шаге 5 словами «расписание уже доступно», хотя у новой группы его нет.
  Дальше студента никто не ведёт.
- На шагах 2 и 4 кнопка «Создать…» видна только при пустом списке; при непустом — путь к
  созданию своего неочевиден.
- Кнопка «+ Добавить» на шаге 7 мелкая и вверху; после сохранения пары в расписании ничего не
  появляется, пока не нажата генерация.
- Экраны 7–8 в стандартном оформлении, не в стиле «Library». В списке дней только
  понедельник–пятница.

**Бэкенд — где путь обрывается**

| Что нужно для пары | Может ли студент сам | Состояние на стенде | Задача |
|---|---|---|---|
| Университет | **нет** — только заявка | работает (M15); решение принято в прошлом плане | — |
| Факультет | да — `POST /students/me/faculty` | работает (M11) | — |
| Группа | да — `POST /students/me/group` | работает (M10) | — |
| Расписание семестра (`WeekScheduleCycle`) | **нет** — только `ADMIN` | у семестра группы, созданной студентом, цикла нет: `404` | B15 |
| Предмет (`Course`) | **нет** — только `ADMIN`/`TEACHER` | каталог общий на все университеты, без отбора | B16 |
| Время пары | **нет** — справочник звонков ведёт `ADMIN` | записи есть только у ДГТУ, записей «по умолчанию» нет | B17 |
| Пара (`Pair`) | да — `POST /pairs` для своей группы в цикле `DRAFT` | работает при выполненном выше | — |
| Занятия (`Lecture`) | да — `POST /lectures/generate/semester/{id}` | работает | — |

Подробности:
- **Цикл.** При создании группы сервер сам заводит учебный год и семестр, но не цикл. Новичок с
  собственной группой видит на шаге 6 «Расписание семестра ещё не открыто администратором» — без
  кнопки.
- **Предмет.** `GET /courses` отдаёт все предметы всех университетов одним списком, с повторами
  названий («Физика», «Программирование» по два раза). У предметов на стенде нет кафедры, а у
  факультета, созданного студентом, нет кафедр вовсе — отобрать «предметы моего факультета»
  нечем. Создать недостающий предмет студент не может.
- **Время.** Приложение не передаёт `startTime`/`endTime`; сервер ищет их в справочнике звонков
  по университету **предмета** (через кафедру), а не студента. У предмета без кафедры поиск идёт
  только по записям «по умолчанию», которых нет, — по коду это `422`. Вживую не проверено.
- **Преподаватель** для пары необязателен: зарегистрированный преподаватель факультета (`teacherId`)
  или имя текстом (`teacherName`, univer#104).
- **Номер и чётность недели** приложение берёт с сервера — `GET /semesters/{id}/week?date=`
  (univer#107, issue #69), по тому же правилу, по которому сервер создаёт занятия: первая неделя —
  календарная неделя (пн–вс) даты начала, нечётная. Вне семестра — `inSemester: false`, строки нет.

## 3. Как работает интерактивный режим

Подсказка — всплывающая плашка у конкретного элемента экрана: одна мысль и одно действие. Она
показывает, куда нажать дальше, и исчезает, когда студент это сделал. В плашке виден и весь путь:
«Факультет → Группа → Первая пара», с отметкой текущего этапа.

### 3.1. Этап «Факультет и группа» — на экранах мастера

| # | Где | У какого элемента | Текст (черновик) |
|---|---|---|---|
| П1 | Профиль или вкладка «Расписание» | кнопка «Завершить настройку» | «До расписания три шага: факультет, группа, первая пара. Начнём» |
| П2 | Шаг «Университет» | поиск | «Найдите свой университет. Если его нет — оставьте заявку» |
| П3 | Шаг «Факультет» | кнопка «Создать факультет» | «Нет вашего факультета? Создайте его — нужно только название» |
| П4 | Форма «Новый факультет» | поле названия | «Напишите так, как называют в вашем вузе. Потом можно исправить» |
| П5 | Шаг «Курс» | список курсов | «Если на вашем курсе групп нет — создадите свою на следующем шаге» |
| П6 | Шаг «Группа» | кнопка «Создать группу» | «Нет вашей группы? Создайте её — одногруппники потом найдут её в списке» |
| П7 | Финал мастера | кнопка перехода к расписанию | «Группа есть. Осталось добавить первую пару» |

Для этого кнопки «Создать факультет» и «Создать группу» должны быть видны и при непустом списке,
а финал мастера у новичка — вести к расписанию группы, а не сообщать «расписание уже доступно».

### 3.2. Этап «Первая пара» — на экранах расписания

| # | Где | У какого элемента | Текст (черновик) |
|---|---|---|---|
| П8 | Вкладка «Расписание» | кнопка «Заполнить расписание группы» | «У вашей группы ещё нет расписания. Добавьте первую пару — это минута» |
| П9 | «Расписание группы» | кнопка «+ Добавить» | «Начните с любой пары, которую помните» |
| П10 | «Добавить занятие» | поле «Курс» | «Выберите предмет. Если его нет — добавьте свой» |
| П11 | «Добавить занятие» | поле «Номер пары» | «Время подставится само» |
| П12 | Вкладка «Расписание», после сохранения | новое занятие | «Готово — это ваша первая пара, она стоит в расписании на весь семестр. Остальные добавляются так же» |

**Занятия создаются сразу.** После «Сохранить» приложение само вызывает
`POST /lectures/generate/semester/{id}` и открывает вкладку «Расписание» на неделе с новым
занятием. Так работает сохранение любой пары, не только первой: вызов идемпотентен и создаёт
занятия только по парам своей группы. Кнопка «Сгенерировать занятия на семестр» остаётся на экране
«Расписание группы» как запасная — на случай, когда пара сохранилась, а занятия нет.

### 3.3. Правила

- **Какую подсказку показать, решают данные сервера**, а не счётчик шагов: профиль
  (университет, факультет, курс, группа), пары группы, занятия. Так режим переживает закрытие
  приложения и начинается с нужного места у студента, зарегистрированного раньше.
- **Режим включается сам** у любого новичка — сразу после регистрации и при следующих запусках,
  пока расписания нет.
- **Подсказку можно закрыть** крестиком или «Понятно» — это хранится на устройстве. Выключить
  весь режим нельзя (issue #66: убраны «Не показывать подсказки» и «Показать подсказки снова»).
- **Подсказка не блокирует экран**: всё остальное остаётся доступным, «Пропустить» в мастере
  работает как раньше.
- **После П12 режим выключается.** Тем, кто выбрал группу с готовым расписанием, подсказки этапа
  «Первая пара» не показываются вовсе.
- Слов «цикл», «шаблон», «черновик», «генерация» в подсказках нет.

## 5. Крайние случаи

- **Университета нет в списке.** Студент оставляет заявку — на этом путь останавливается до
  решения администратора. Подсказка говорит об этом прямо; после добавления университета режим
  продолжается с шага «Университет».
- **Студент выбрал существующую группу с расписанием.** Он больше не новичок — режим выключается
  сразу после мастера, без «Первой пары».
- **Студент выбрал существующую группу без пар.** Режим продолжается с П8.
- **Расписание согласовано** (`AGREED`). Добавлять пары студент не может — подсказки этапа
  «Первая пара» не показываются, остаётся нынешний текст «обратитесь к администратору».
- **Дубль названия факультета или группы** (`409`). Форма предлагает выбрать существующую запись,
  как сейчас; подсказка не должна перекрывать это предложение.
- **Аудитория в это время занята** — `422` на форме пары; подсказка не должна перекрывать
  сообщение об ошибке.
- **Семестр закончился или ещё не начался.** Занятия создадутся не на текущей неделе — П12
  должна привести на неделю, где первое занятие есть.
- **Пара сохранилась, а занятия не создались** (обрыв сети между двумя запросами). Приложение
  повторяет только создание занятий, вторую пару не заводит; на вкладке «Расписание» в этом
  состоянии — кнопка «Показать пары в расписании» вместо пустого экрана.
- **Студент закрыл приложение посреди пути.** При запуске показывается подсказка, которая
  соответствует данным: например, группа уже есть — сразу П8.
- **Студент нажал «Пропустить» в мастере.** Режим не настаивает: П1 остаётся у кнопки «Завершить
  настройку», пока студент её не закроет.
- **Студент сменил группу или факультет** и снова остался без расписания. Режим включается
  заново, если студент его не выключал.

## 7. Чек-лист приёмки

- [ ] Новый студент без университета → подсказка П1, затем подсказки на шагах мастера.
- [ ] Факультета нет в списке → П3 ведёт к «Создать факультет», П4 на форме.
- [ ] Группы нет → П6 ведёт к «Создать группу»; финал мастера ведёт к расписанию группы (П7).
- [ ] «Создать факультет» и «Создать группу» видны и при непустом списке.
- [ ] Подсказки П8–П11: от вкладки «Расписание» до формы пары.
- [ ] Выбрал предмет из списка своего факультета; добавил свой предмет.
- [ ] Рядом с номером пары показано время — в том числе у университета без своих звонков.
- [ ] Сохранил пару → без других действий открылось расписание с занятием и П12; режим выключился.
- [ ] Студент, зарегистрированный до спринта, без пар → режим включился с нужного места.
- [ ] Обрыв сети после сохранения пары → повтор создаёт занятия, второй пары нет.
- [ ] Закрыл приложение после создания группы → после запуска П8, а не П1.
- [ ] Закрыл подсказку → она не появляется снова.
- [ ] Выбрал группу с готовым расписанием → подсказок этапа «Первая пара» нет.
- [ ] Университета нет в списке → заявка, подсказка объясняет, что путь продолжится после добавления.
- [ ] Конфликт аудитории и дубль названия → сообщение формы видно, подсказка его не перекрывает.
